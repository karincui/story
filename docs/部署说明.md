# 部署说明（Vercel + Supabase）

本文记录本项目的线上方案，避免以后忘记怎么发布、改哪里。

## 架构

| 部分 | 用什么 | 作用 |
|------|--------|------|
| 前端网页 | **Vercel** | 托管 `npm run build` 后的静态站点 |
| 登录 + 书单数据 | **Supabase** | 邮箱 + 密码登录、云端数据库 |
| 代码仓库 | **GitHub** | [https://github.com/karincui/story](https://github.com/karincui/story) |

本地截图图库仍在本机 IndexedDB，不上云。

**访问说明**：`*.vercel.app` 在中国大陆通常打不开，需要手机/电脑翻墙后再访问。这是当前「免费国外方案」的取舍。

## 环境变量（必填）

本地用 `.env`（已在 `.gitignore`，不要提交到 Git）。  
线上在 **Vercel → 项目 → Settings → Environment Variables** 配置同样两项：

| 变量名 | 说明 |
|--------|------|
| `VITE_SUPABASE_URL` | Supabase 项目 URL，形如 `https://xxxx.supabase.co` |
| `VITE_SUPABASE_ANON_KEY` | Supabase 的 anon / publishable key |

可参考仓库根目录 `.env.example`。  
注意：Vite 变量在**构建时**打进前端，改完环境变量后需要 **Redeploy** 一次才生效。

## 首次：Supabase 准备（若尚未做过）

1. 打开 [Supabase Dashboard](https://supabase.com/dashboard)，进入你的项目  
2. **SQL Editor** 执行仓库里的 `supabase/schema.sql`  
3. **Authentication → Providers**：确认 Email 已开启  
4. 记下 Project URL 与 anon key，填到本地 `.env` / Vercel 环境变量  

## 发布到 Vercel

1. 打开 [https://vercel.com/new](https://vercel.com/new)  
2. 用 GitHub 登录，Import 仓库 **`karincui/story`**  
3. Root Directory 保持默认（仓库根目录即前端）  
4. Framework Preset 一般会识别为 Vite；Build Command：`npm run build`；Output：`dist`  
5. 添加上面两个环境变量后点 **Deploy**  
6. 部署成功后记下地址。当前生产域名：  
   **https://story-jade-six.vercel.app**  
   （若以后改过域名，以 Vercel → Project → Domains 为准）

常用入口：

- 注册 / 登录：[https://vercel.com/signup](https://vercel.com/signup)  
- 控制台：[https://vercel.com/dashboard](https://vercel.com/dashboard)  

之后每次把代码 `push` 到 GitHub 的 `main`，Vercel 一般会自动重新部署。

## 部署后必须改：Supabase 回调地址

登录已改为 **邮箱 + 密码**（不再发 Magic Link）。URL 配置仍建议填对，以便以后开邮件确认或找回密码。

1. Supabase → **Authentication → URL Configuration**  
2. **Site URL** 改成线上地址，例如：`https://story-jade-six.vercel.app`  
3. **Redirect URLs** 里加上同一地址（可保留 `http://localhost:5173` 方便本地开发）  
4. **Authentication → Providers → Email**：建议关闭 **Confirm email**，注册后可立刻用密码登录（个人项目够用）

本地开发仍用：

```bash
cd novel-app   # 或本仓库根目录
npm install
npm run dev
```

## 本地改代码后如何更新线上

```bash
git add -A
git commit -m "说明这次改了什么"
git push origin main
```

到 Vercel Dashboard 看最新 Deployment 是否成功。若只改了环境变量，在 Vercel 里对最新部署点 **Redeploy**。

## 常见问题

| 现象 | 处理 |
|------|------|
| 大陆打不开网站 | 开启 VPN / 翻墙后再访问 |
| 能打开但登录没反应 / 跳错站 | 检查 Supabase Site URL、Redirect URLs 是否已改成 Vercel 域名 |
| 线上没有数据或报缺 key | 检查 Vercel 环境变量名是否完全一致，并 Redeploy |
| 忘记 schema | 再执行一次 `supabase/schema.sql`（注意勿重复破坏已有数据，按 SQL 内容判断） |
